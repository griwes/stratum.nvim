INTRODUCTION                                                       *stratum*

Stratum maintains cached Git repository state through one Gitseer worker per
repository. It is a shared state substrate, not a Git UI. Neovim 0.11 or newer
and a compatible `gitseer` executable are required.

==============================================================================
SETUP                                                     *stratum-setup*

>lua
    require('stratum').setup({
        gitseer = {
            command = 'gitseer',
            auto_start = true,
        },
    })
<

==============================================================================
API                                                         *stratum-api*

Common functions are `start()`, `stop()`, `repo_for_path()`, `ensure_repo()`,
`state()`, `summary()`, `snapshot_summary()`, `subscribe()`, and `refresh()`.

Repository updates emit the `User StratumRepositoryUpdated` event. Stratum also
ships the optional runtimepath widget `statuesque.widgets.git_repo`.
