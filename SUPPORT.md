# Support

Use the repository's bug report form for reproducible defects and the feature request form for proposed behavior. Include the exact revision, operating system, and output of `:checkhealth stratum` plus `nvim --version`.

Only the current `main` branch is supported before the first stable release. Configuration debugging, compatibility with unrelated plugins, and custom integrations are handled on a best-effort basis.

Do not include credentials, tokens, private source code, terminal output containing secrets, or vulnerability details in public reports. Follow [SECURITY.md](SECURITY.md) for security issues.
